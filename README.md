# ReviewDesk

ReviewDesk è un'applicazione web per la gestione delle recensioni Google e delle richieste SMS per piccoli esercenti (con particolare attenzione al Ticino).

## Configurazione

Per il funzionamento delle funzioni di intelligenza artificiale (generazione bozze di risposta e sintesi recensioni), è necessario configurare la chiave API sul server tramite la variabile d'ambiente:

`OPENROUTER_API_KEY=la_tua_chiave`

## Sviluppo e Avvio

- `npm run dev`: Avvia il server di sviluppo con Vite.
- `npm run build`: Compila l'applicazione per la produzione.
- `npm start`: Avvia il server in produzione.
